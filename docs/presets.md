# Factory preset

The bundled factory is an instrumental study of the Flowers / Sunship intro, using synthesized sounds rather than source recording or vocals. It is an arrangement reference, not a claim of ownership of the song.

Tempo: **132 BPM**. Eight patterns form the saved factory chain. Other sound slots remain empty.

| Slot | Sound |
| --- | --- |
| 1 | Rounded C2 sub |
| 2 | Tine keys C5 |
| 3 | Soft organ C4 |
| 4 | Glass bell C5 |
| 9 | 2-step composite kit |
| 10 | Minor / soul chord stabs |
| 11 | Hat / shaker variations |
| 12 | Rim / clap / tom kit |

The sample source is `presets.js`; rebuild with `node scripts/build-factory-presets.cjs`. The procedural sound synthesis is original; the reference arrangement and third-party assets are not automatically covered by that sound license.
