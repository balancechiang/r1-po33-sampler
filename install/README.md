# Install on rabbit r1

Open Creations → create → add via QR code and scan `creation-qr.png`.
The QR encodes `creation.json`, matching the previous installation metadata.
It points to https://balancechiang.github.io/r1-po33-sampler/ with the same
title, description, icon URL and theme color. Existing installation QR codes
remain valid. Updating the repository does not require reinstalling the Creation.

The PNG has a four-module white quiet zone; the SVG is also available for print.
AudioWorklet and microphone access require the HTTPS Pages URL. Physical R1
USB audio and PO-33 transfer acceptance are still pending; see ../BACKUP-IO.md.

简体中文：在 r1 的 Creations 中选择通过二维码添加，扫描本目录 PNG。
网址和安装信息与旧版一致，已有二维码仍然有效，无需重新安装来更新网页。
