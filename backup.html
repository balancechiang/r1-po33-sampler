Hardware backup

Raw stereo recording and replay · 44.1 kHz / 16-bit PCM

This page records or replays raw hardware backup audio. To try decoded sounds and patterns without replacing your saved project, open project audition / 工程试听. Generating a hardware backup from the web project is not implemented yet.

1 · Connect

Use a stereo audio interface and a stereo cable. Disable system sound effects, EQ and spatial audio. The browser can verify its own format, but cannot verify the operating system or interface signal path.

A verified two-channel 44.1 kHz input is required for recording.

2 · Receive from PO-33

Connect PO-33 line out to the interface input. Start recording here, then press WRITE + SOUND + PLAY on the PO-33. Stop here after its transfer finishes.

No signal measured.

3 · Save or replay

Or drop a WAV here. MP3 and other formats are not converted in the backup path.

No backup audio loaded.

To replay to hardware: connect the selected output to PO-33 line in, set the PO-33 to receive with WRITE + SOUND + RECORD, then play below. Receiving replaces the hardware's current sounds and patterns. Set and test interface volume manually; this page applies no gain or normalization.
