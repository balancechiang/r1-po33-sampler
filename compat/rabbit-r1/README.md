# rabbit r1 compatibility

Web Sampler is a browser application. Rabbit r1 Creations is an optional host for its compact layout, scroll wheel, side button and haptics.

Scan [install-qr.png](install-qr.png) in the Creation installation flow. The code embeds the complete [creation.json](creation.json) object, following the [official SDK generator](https://github.com/rabbit-hmi-oss/creations-sdk/blob/main/qr/final/js/app.js). It opens the stable `/creation.html` compatibility loader, which loads the main web page. It is not a project-download QR.

The adapter maps the wheel to tempo/selection and the side button to play or held record. Browser features still depend on WebView permissions and device support. No OS3 model/API key is required by the application.

This independent project is not affiliated with Teenage Engineering or endorsed by rabbit. Existing host storage keys remain unchanged; ordinary updates preserve user projects.
